          schema·board — what it can do
          

            
          

        

        

          

            
Navigate the canvas

            
drag backgroundPan around

            
scrollZoom in / out (or the ＋ / － controls)

            
FFit everything to the screen

            
✦Auto-arrange tables (crossing-reducing layout)

            
minimapBird's-eye overview, top-right

          


          

            
Tables & relationships

            
drag headerMove a table (position is remembered per file)

            
click tableOpen the inspector — columns, enum values, what references it, indexes

            
←↑↓→Move selection to the nearest table (smoothly focuses it)

            
hover tableHighlight its relationships, dim the rest

            
double-clickToggle inline "was → now" detail on changed columns

            
crow's-footCardinality on wires: fork = many, bar = one, ○ = optional FK

            
⇧-click tableJoin path: select one table, shift-click another — the path lights up and the JOIN SQL is written for you

            
hover wireTooltip with the exact relation (orders.user_id → users.id · on delete cascade)

            
⇧-drag canvasRubber-band select several tables, then drag any one to move the group

            
color tagClick a table → pick a color in the inspector to group tables by domain

            
.Focus mode: show only the selected table + its neighbors (press again for 2 hops, again to exit)

            
⌘ZUndo the last layout change (drag or auto-arrange)

          


          

            
Diff & versions

            
DToggle diff coloring (added / modified / removed)

            
Changes onlyHide everything that didn't change

            
click versionView that version in the diagram

            
⌘-click versionSet it as the comparison baseline

            
migrations / saveWith a migrations folder, each SQL file is a version (+ Latest from Drizzle). Otherwise each save captures a version.

            
⏱ ReplayTime machine — watch the schema evolve version by version (space play/pause)

          


          

            
Review & feedback

            
Review tabSQL best-practice findings (missing FK indexes, money-as-float, …)

            
✨ Deep reviewFull review by your local Claude Code CLI — no API key

            
＋Add any change or finding to your feedback list

            
Feedback tabCopy a ready-to-paste prompt for your coding agent
