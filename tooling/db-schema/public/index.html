Canvas

            
Drag backgroundPan the board

            
ScrollZoom in or out (also ＋ / －)

            
FFit all tables to the screen

            
✦Auto-arrange tables

            
MinimapBird’s-eye overview (top-right)

            
⇧-dragRubber-band select tables, then drag any one to move the group

          


          

            
Tables

            
Drag headerMove a table (layout is remembered)

            
Click tableOpen inspector — columns, indexes, references

            
Hover tableHighlight its relationships, dim the rest

            
Double-clickToggle “was → now” detail on changed columns

            
Module colorTables in the same schema/module share a header color

            
.Focus mode — selected table + neighbors (again = 2 hops, again = exit)

            
⌘ZUndo last layout change

            
←↑↓→Jump selection to the nearest table

          


          

            
Relationships

            
Crow’s-footFork = many, bar = one, ○ = optional FK

            
Hover wireTooltip with the exact relation and on-delete

            
⇧-click tableJoin path — pick two tables to light the path and copy JOIN SQL

          


          

            
Diff & versions

            
DToggle diff colors (added / modified / removed)

            
Changes onlyHide tables that did not change

            
Click versionView that version (closes the table inspector)

            
⌘-clickSet a version as the comparison baseline

            
MigrationsEach SQL file is a version; tip is Latest

            
⏱ ReplayTime machine — watch versions evolve (Space play/pause)
